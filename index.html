🔑 Credentials
ℹ️ How to get credentials
  1. Sign up at cloud.ibm.com
  2. Create a watsonx.ai service instance
  3. Create a new Project in watsonx.ai Studio
  4. Generate an API Key from IBM Cloud → Manage → API Keys
  5. Copy your Project ID from the project settings page
  6. Paste both values above and click Save
Demo Mode: Without credentials all agents run using built-in rule-based ML logic. All dashboard, monitoring, quality, defect, and optimization features are fully functional.
